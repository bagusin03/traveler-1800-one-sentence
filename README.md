One Road, Every Letter: a single sentence explaining the modern internet to a traveler from 1800, for the make.fun "One Sentence for a Traveler from 1800" bounty. `main.ts` writes one 189-character sentence to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> Picture a road joining every post office and library on earth, where a letter arrives before its ink dries, any book opens at your word, and a friend across the sea speaks as if beside you.

Every word in it is one a person from 1800 would already know — a road, a post office, a library, the three anchors the judge brief itself names — with nothing coined after their time and no list of features. One road carries all three things the internet does: letters that arrive before their ink dries, any book opening at your word, and a friend across the sea speaking as if beside you.

## Run it

```sh
node main.ts
```
